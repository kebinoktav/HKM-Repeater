
## Intended Use
HKM is intended to generate repetitive mouse and keyboard input 
with flexible input actions.


# Feature
- keyboard output repetition
- mouse output repetition
- configurable input action
- configurable output action

# Installation

Download the latest release for your operating system from the Releases page.

Alternatively, build HKM Repeater from source:

git clone https://github.com/YOUR_USERNAME/hkm_repeater.git
cd hkm_repeater
cargo build --release

# Usage

Launch HKM Repeater and configure the keyboard or mouse actions you want to repeat.
# Basic Workflow

1. Start the repeater.
2. Define the input/output actions.
3. Define the timing and timing options.
4. Submit the configuration.
5. Click or interact with the input target you have defined.
